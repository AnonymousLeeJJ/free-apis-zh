## 🤔 为什么做这个库？

写项目练手、做 demo、参加比赛时，最缺的就是**顺手的数据接口**。网上很多 API 合集要么全是国外的、要么早已失效、要么不标清楚要不要注册。

本库的原则：

- ✅ 每个 API 都标注 **是否需要注册 Key**
- ✅ 附**可直接粘贴的示例请求**
- ✅ 优先收录国内可稳定访问的服务
- ✅ 定期清理失效接口

## 🚀 快速开始

1. 打开 **[在线浏览页面](https://anonymousleejj.github.io/free-apis-zh/)**
2. 点 **🆓 无需 Key** 筛掉要注册的接口
3. 复制示例请求，直接在你的项目里用
